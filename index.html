01 Sobre mim

Meu nome é Julia Leonel e estou me formando técnica em Tecnologia da Informação no Cotemig. Comecei pelo front-end e hoje trabalho os três lados de uma aplicação: a tela, a lógica e os dados.

No front-end uso HTML semântico, CSS com Flexbox e Grid e JavaScript puro, sempre pensando em responsividade. No banco de dados trabalho com MySQL — modelagem, relacionamento entre tabelas e consultas SQL. Em C# estudo lógica, orientação a objetos e a conexão da aplicação com o banco.

Sou organizada, pergunto quando não sei e entrego o que combinei. Procuro estágio para aplicar isso em projeto real.

Estudando agora

  • Consultas SQL com JOIN e subconsultas
  • Orientação a objetos em C#
  • Git e versionamento de código
